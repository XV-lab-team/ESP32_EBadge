## 2. 核心库 `src/`（GB2312 原样拷贝，移植时整组加入编译）

| 文件 | 改不改 | 角色 |
|------|--------|------|
| `src/shell.c` | 默认不改 | 解析、帮助、历史、`shellInit`/`shellTask` |
| `src/shell.h` | 默认不改 | API 与 `SHELL_EXPORT_CMD*` |
| `src/shell_cfg.h` | 通了再改提示符等 | 功能开关 |
| `src/shell_ext.c` | 不改、不要开 AUTO_PRASE | 自动解析（本配置未用） |
| `src/shell_ext.h` | 不改 | 同上 |
| `src/ring.c` | 不改 | 环形缓冲 |
| `src/ring.h` | 不改 | 同上 |

对应教具路径：`USER/letter_shell/` 同名文件（教具另有 `shell_app.c`，不在 `src/`）。

## 3. 胶水草稿 `glue/`（UTF-8，必须按目标板改）

| 文件 | 角色 |
|------|------|
| `glue/shell_app.c` | 任务、`read`/`write`、示例命令 `hello` |
| `glue/shell_app.h` | `shell_app_task` 声明 |
| `glue/keil_shell.sct.inc` | Keil scatter 片段 |
| `glue/gcc_shell.ld.inc` | GNU ld 片段 |

`glue/shell_app.c` 依赖：`UART_HandleTypeDef`、FreeRTOS。拷过去后补 `#include "main.h"`（或目标工程的 UART 头）。

## 4. 教具参考 `examples/`（GB2312，只读）

| 文件 | 角色 |
|------|------|
| `examples/本工程_shell_app.c` | 教具真实胶水 + UAV 命令，**有 `uav.h`/`bsp.h` 依赖** |
| `examples/本工程_shell_app.h` | `shell_app_task` 声明 |
| `examples/README.md` | 怎么读这两份参考 |

教具创建任务的代码在仓库 `USER/Logic/logic.c`（`xTaskCreate(shell_app_task, ... SHELL_TASK_STACK=512)`），未再复制一份，避免和产品逻辑绑死。
