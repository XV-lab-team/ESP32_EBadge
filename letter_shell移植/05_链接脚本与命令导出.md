# 05 — 链接脚本与命令导出

`SHELL_USING_CMD_EXPORT == 1` 时，每条命令是一个放进 **`shellCommand`** 段的 `const SHELL_CommandTypeDef`。  
`shellInit()` 用段的起止地址除以结构体大小，得到命令个数。

**段丢掉 = `help` 几乎是空的。** 这是移植第一杀手。

---

## 1. 宏展开后是什么

`src/shell.h`（`SHELL_LONG_HELP==1`）大致变成：

```c
const char shellCmdhello[] = "hello";
const char shellDeschello[] = "hello test";
const char shellHelphello[] = "hello";
const SHELL_CommandTypeDef shellCommandhello
    __attribute__((section("shellCommand"))) = {
        shellCmdhello, (int (*)())shell_cmd_hello, shellDeschello, shellHelphello
    };
```

链接器必须把所有 `section("shellCommand")` 的对象**连续**收进同一段，且**不要当未引用而删除**。

---

## 2. `shellInit` 如何找这段

见 `src/shell.c` 的 `shellInit()`：

| 编译器宏 | 起止符号 |
|----------|----------|
| `__CC_ARM` 或 ARMClang `__ARMCC_VERSION >= 6000000` | `shellCommand$$Base` / `shellCommand$$Limit` |
| `__ICCARM__` | `__section_begin("shellCommand")` / `__section_end` |
| `__GNUC__` | `_shell_command_start` / `_shell_command_end`（**必须你在 ld 里 PROVIDE**） |

教具用 Keil ARMCC，scatter **即使不写 `*(shellCommand)` 有时也能链上**（工具链给命名段生成 `$$Base/$$Limit`）。目标工程若开了 **未使用段删除**（`--remove`、`--gc-sections`），必须 **KEEP**。

---

## 3. Keil / ARMCC / ARMClang

把 `glue/keil_shell.sct.inc` 贴进 `ER_IROM1`，放在 `.ANY (+RO)` **之前**：

```
LR_IROM1 ... {
  ER_IROM1 ... {
    *.o (RESET, +First)
    *(InRoot$$Sections)
    *(shellCommand)
    .ANY (+XO)
    .ANY (+RO)
  }
  ...
}
```

或链接命令行加：

```
--keep=*(shellCommand)
```

查 `.map`：搜索 `shellCommand`，应能看到 `hello`、`help`、`cls` 等符号。

---

## 4. GCC（STM32CubeIDE / Makefile）

`shell.c` 的 GNU 分支读的是 **`_shell_command_start` / `_shell_command_end`**，不是 `__shellCommand_start` 之类。  
把 `glue/gcc_shell.ld.inc` 放进 `.text` 所在 MEMORY 的 FLASH 输出段（与其它 RO 一起，注意对齐）。

必须 `KEEP`，否则 `--gc-sections` 会删掉没有任何引用的命令对象。

IAR 用 `keep { section shellCommand };`（以你工程的 icf 语法为准），走 `shell.c` 里 `__ICCARM__` 分支。

---

## 5. 命令写在哪个 .c

任意**会被链接**的 `.c` 都可以 `SHELL_EXPORT_CMD_EX`。  
该文件只要被编译，即使没有别的函数引用这条命令，也要靠 **KEEP 段** 保住。

不要把命令只写在被条件编译裁掉的文件里。

---

## 6. 命令原型与导出宏

```c
SHELL_EXPORT_CMD(name, func, desc);
SHELL_EXPORT_CMD_EX(name, func, desc, help);
```

- `name`：C 标识符，同时 `#name` 变成命令字符串，故命令名必须是合法标识符（不要 `foo-bar`）  
- `func`：`int func(int argc, char *argv[])`  
- `desc`：`help` 列表里的短描述  
- `help`：对命令再执行 `help name` 或双击 Tab（需 `SHELL_GET_TICK()` 有效）时的长说明  

打印用：

```c
SHELL_TypeDef *sh = shellGetCurrent();
shellPrint(sh, "x=%d\r\n", x);
```

`shellGetCurrent()` 仅在命令执行期间有效（`isActive`）。

---

## 7. 备选：命令表（关掉段导出）

`shell_cfg.h`：`SHELL_USING_CMD_EXPORT 0`。  
用 `SHELL_CMD_ITEM` / `SHELL_CMD_ITEM_EX` 填表，或 `shellSetCommandList()`。  
仅当步骤 2 链接段失败且无法改脚本时使用。
