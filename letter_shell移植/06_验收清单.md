# 06 — 验收清单

移植者逐项打勾。全部通过才能对用户说「shell 已移植完成」。

---

## A. 编译与链接

- [ ] `src/` 7 个文件已加入目标工程并编译  
- [ ] Include Path 能找到 `shell.h` / `ring.h` / `shell_cfg.h`  
- [ ] map 中存在 `shellCommand` 段（GCC 则有 `_shell_command_start`）  
- [ ] 未误开 `SHELL_AUTO_PRASE`

## B. 启动显示

- [ ] 复位后 Debug 串口出现 letter-shell ASCII 横幅  
- [ ] 有 `Version:     2.0.8`  
- [ ] 有提示符（默认同教具 `XV>>`，若已改则提示符为你改的字符串）

## C. 输入与内置命令

- [ ] 终端已关本地回显，键入可见单份回显  
- [ ] `help` 列出 `help`、`cls`、胶水里的 `hello`  
- [ ] `hello` 打印 `hello letter-shell`  
- [ ] `cls` 清屏（需 VT100 终端）  
- [ ] 上/下键能翻历史（至少输入过两条命令之后）  
- [ ] Tab 能补全唯一前缀

## D. 自建命令

- [ ] 在目标工程自己的 `.c` 增加一条 `SHELL_EXPORT_CMD_EX`  
- [ ] `help` 能看到它  
- [ ] 执行行为符合函数逻辑

## E. 稳定性

- [ ] 连续敲 `help` 十余次不死机  
- [ ] 任务栈未在 `configCHECK_FOR_STACK_OVERFLOW` 下报警（若已开检查）  
- [ ] shell 口与其它协议口（屏/遥控）不是同一 UART

## F. 明确不要验收的（本包范围外）

- 教具 UAV 命令：`motor_scale` / `servo_scale` / `ctr_en` / `os_stats` 等  
- 串口屏、故障注入、Flash KV  

---

## 失败时回看

| 失败项 | 文档 |
|--------|------|
| 无横幅 | `02` TX、波特率 |
| 有横幅无输入 | `02` RX → ring |
| 无 `hello` | `05` 段 KEEP |
| 死机 | `02` 栈 512 字；`00` `SHELL_TASK_WHILE` |
