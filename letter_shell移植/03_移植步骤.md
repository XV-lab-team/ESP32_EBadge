# 03 — 移植步骤（一层一做）

按顺序做。每步有可观察结果；不要跳步把命令、链接、UART 一次改完再猜。

目标工程的目录名可自定。下文用：

- `目标/letter_shell/` ← 拷 `src/`  
- `目标/letter_shell/shell_app.c` ← 以 `glue/shell_app.c` 为草稿改  

---

## 步骤 0 — 读文档、定 UART

**做：**

- 读完 `00` `01` `02`  
- 确定 Debug UART 外设、引脚、波特率（用户用 CubeMX 配好，已能 printf 或串口助手看到数据更佳）  
- 确定编译器：Keil ARMCC / ARMClang / GCC / IAR  

**验收：** 写下「UART=USARTx，波特率=xxxx，编译器=xxxx」。

---

## 步骤 1 — 拷核心源码进工程

**做：**

1. 把本包 `src/` 下 7 个文件拷到目标工程（建议独立组 `letter_shell`）  
   - `shell.c` `shell.h` `shell_cfg.h`  
   - `shell_ext.c` `shell_ext.h`  
   - `ring.c` `ring.h`  
2. Include Path 加上该目录  
3. **先不要改** `shell.c` / `shell.h` / `ring.*` / `shell_ext.*`  
4. `shell_cfg.h` 先保持本包默认（见 README 表）  

**验收：** 工程能编译这些文件（此时还缺 `read`/`write` 和任务，链接可能报未使用，只要文件已加入编译）。

---

## 步骤 2 — 链接命令段（本步最容易漏）

**做：** 按编译器改链接脚本，详见 `05`。

- Keil：scatter 的 RO 区加入 `*(shellCommand)`，或链接选项 `--keep=*(shellCommand)`  
- GCC：加入 `glue/gcc_shell.ld.inc` 的 `KEEP(*(shellCommand))` 和 `_shell_command_start/_end`  
- IAR：给 `shellCommand` 段 keep，且 `shell.c` 已支持 `__section_begin("shellCommand")`  

**验收：** map 文件里能搜到 `shellCommand`，并且稍后步骤 5 的 `help` 能看到 `hello`。若只有 `help`/`cls`，**停在本步**，不要先加业务。

---

## 步骤 3 — 写胶水（RX/TX + 任务）

**做：**

1. 拷 `glue/shell_app.c` `glue/shell_app.h`  
2. 改 UART 句柄、TX 标志位、RX 喂 ring 的代码  
3. `#include` 目标板的 `main.h` / `usart.h` / `FreeRTOS.h`  
4. 在已有启动任务里 `xTaskCreate(shell_app_task, "shell", 512, NULL, osPriorityNormal, NULL)`  
5. 栈不够再加到 768/1024 字  

**不要做：** 把 `examples/本工程_shell_app.c` 整文件贴过去（里面 `#include "uav.h"` 等教具依赖）。

**验收：** 编译通过，下载后串口出现 letter-shell ASCII 横幅和提示符。

横幅特征（英文）：

```text
 _         _   _                  _          _ _
| |    ___| |_| |_ ___ _ __   ___| |__   ___| | |
...
Version:     2.0.8
```

提示符本包为 `XV>>`（`SHELL_DEFAULT_COMMAND`）。可改，但本步先别改，方便对照。

---

## 步骤 4 — 终端回车

**做：** 终端关闭本地回显，波特率与 Cube 一致，输入 `help` 回车。

**验收：**

- 能列出至少：`help`、`cls`、`hello`  
- 输入 `hello` 回车，看到 `hello letter-shell`  
- 返回值打印一行（`SHELL_DISPLAY_RETURN==1`，格式在 `shell.c` 的 `shellDisplayReturn`）

若无 `hello`：回到步骤 2。  
若按键无回显：RX 没进 ring，或 `read` 接错。  
若双字符：关掉终端本地回显。

---

## 步骤 5 — 加一条目标工程自己的命令

在**目标工程自己的 .c**（不要改 `src/shell.c`）写：

```c
#include "shell.h"

static int shell_cmd_id(int argc, char *argv[])
{
    SHELL_TypeDef *sh = shellGetCurrent();
    (void)argc;
    (void)argv;
    if (sh)
        shellPrint(sh, "board ok\r\n");
    return 0;
}
SHELL_EXPORT_CMD_EX(id, shell_cmd_id, "board id", id);
```

该 .c 必须被编译进最终镜像。

**验收：** `help` 出现 `id`；执行 `id` 打印 `board ok`。

---

## 步骤 6 — 按需改配置（通了再改）

可以改的：

| 项 | 文件 |
|----|------|
| 提示符 | `shell_cfg.h` → `SHELL_DEFAULT_COMMAND` |
| 行长 / 历史条数 | 同文件 |
| `SHELL_GET_TICK()` | 改为 `HAL_GetTick()` 后，双击 Tab 才有长 help 计时 |

不要改的（除非你要改命令模型并同步改所有命令）：

- `SHELL_AUTO_PRASE` 保持 `0`  
- `SHELL_TASK_WHILE` 保持 `0`（除非 `read` 改成阻塞）  
- `SHELL_USING_CMD_EXPORT` 保持 `1`（除非你改用命令表，见 `05` 备选）

---

## 步骤 7 — 对照验收表

打开 `06_验收清单.md` 逐项打勾。全部通过才算移植完成。

---

## 备选：不用段导出（仅当链接段实在做不通）

把 `SHELL_USING_CMD_EXPORT` 改为 `0`，在 `shell.c` 的 `shellDefaultCommandList[]` 或启动后 `shellSetCommandList()` 注册命令。  
这是退路，与本教具不一致；能用段导出时不要走这条。
