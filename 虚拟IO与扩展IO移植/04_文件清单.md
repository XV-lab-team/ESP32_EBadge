# 04 — 文件清单

路径均相对 `虚拟IO与扩展IO移植/`。

## 1. 说明（UTF-8）

| 文件 | 用途 |
|------|------|
| `README.md` | 入口 |
| `00_给接手AI.md` | 边界、编码、禁令 |
| `01_架构与模块说明.md` | 分层与驱动行为 |
| `02_HAL与I2C引脚.md` | I2C / RST / 任务 |
| `03_移植步骤.md` | 动手步骤 |
| `04_文件清单.md` | 本文件 |
| `05_配置表与逻辑编号.md` | 脚表规则 + 教具新板全表 |
| `06_验收清单.md` | 自测 |

## 2. 核心库 `src/`（UTF-8，移植时整组加入编译）

| 文件 | 改不改 | 角色 |
|------|--------|------|
| `src/aw9523.c` | 默认不改行为 | 寄存器、缓存、I2C 写 |
| `src/aw9523.h` | 默认不改 | API 与引脚位掩码 |
| `src/aw9523_port.h` | **按目标板改** | RST 宏、日志、补 `i2c.h` |
| `src/exio.c` | 不改 | 按表 init / apply |
| `src/exio.h` | 不改 | `exio_t` 与 64 槽表 |

对应教具路径：`USER/Chip/aw9523.*`、`USER/APP/exio.*`。本包 `src` 已去掉对教具 `bsp.h` / `log.h` 的依赖。

## 3. 胶水草稿 `glue/`（UTF-8，必须按目标板改）

| 文件 | 角色 |
|------|------|
| `glue/io_virtual.c` | 队列、任务、**芯片 AD + 脚表**（默认 1 片 + demo 脚） |
| `glue/io_virtual.h` | `vio_*` 枚举与 API |

`glue/io_virtual.c` 依赖：`I2C_HandleTypeDef`、RST 宏、FreeRTOS 队列。拷过去后改 `VIO_I2C` / `VIO_RST_*`。

## 4. 教具参考 `examples/`（GB2312，只读）

| 文件 | 角色 |
|------|------|
| `examples/本工程_aw9523.c` / `.h` | 教具芯片驱动原件（含 `bsp.h`/`log.h`） |
| `examples/本工程_exio.c` / `.h` | 教具 exio 原件 |
| `examples/本工程_io_virtual.c` / `.h` | 教具新 PCB 三片全脚表 + 诊断任务 |
| `examples/README.md` | 怎么读这些参考 |

教具创建任务的代码在仓库 `USER/Logic/logic.c`（`xTaskCreate(io_virtual_task, ... 2048)`），未再复制一份。

## 5. 不要当本包一部分的东西

| 路径 | 原因 |
|------|------|
| `USER/BSP/bsp_gpio.h` | 仅教具 BSRR 宏；本包 port 已用 HAL_GPIO |
| `USER/Formula/log.h` | 教具日志；目标用 port 宏或自己的 log |
| `USER/APP/uav_fault.c` / `uav_exec.c` | 教具业务，不是驱动 |
| `Core/` | Cube 生成，禁整份覆盖 |
