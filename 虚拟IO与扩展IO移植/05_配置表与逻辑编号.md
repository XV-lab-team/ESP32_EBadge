# 05 — 配置表与逻辑编号

改脚只改 **胶水里的枚举 + 两张 cfg 表 + `aw9523_dev_cfg`**。不要改 `aw9523.c` 去「直接写某个寄存器」。

---

## 1. 硬性对齐规则

1. `vio_gpio_id_t` 从 0 连续排到 `VIO_GPIO_NUM-1`
2. `exio_gpio_pin_cfg[i]` 描述的就是枚举值 `i`
3. LED 同理：`vio_led_id_t` ↔ `exio_led_pin_cfg[]`
4. **只在 `*_NUM` 之前追加**新 ID，禁止在中间插入（否则旧业务下标全错）
5. 未用槽保持全 0（`pin == AW9523_PIN_NULL`）
6. 同一 `(chip_num, pin)` 只能出现一次（GPIO 表内部、以及 GPIO↔LED 之间）

`chip_num` 是 **0 基下标**，最大值 `< chip_num` 且 `< 4`。

---

## 2. 地址计算

```
addr8 = 0xB0
if (a0) addr8 |= 0x02
if (a1) addr8 |= 0x04
```

| AD1 | AD0 | a1 | a0 | 8 位写地址 |
|-----|-----|----|----|------------|
| 0 | 0 | 0 | 0 | `0xB0` |
| 0 | 1 | 0 | 1 | `0xB2` |
| 1 | 0 | 1 | 0 | `0xB4` |
| 1 | 1 | 1 | 1 | `0xB6` |

原理图若写「7 位地址 0x58」，对应 HAL 8 位写地址 `0xB0`。

---

## 3. 引脚枚举（位掩码）

`AW9523_PIN_0_0` … `AW9523_PIN_0_7` 是 P0.0~P0.7（bit0~7）。  
`AW9523_PIN_1_0` … `AW9523_PIN_1_7` 是 P1.0~P1.7（bit8~15）。  
cfg 里填其中一个，不要填 `AW9523_PIN_ALL`。

---

## 4. LED DIM 乱序（只读，勿自己重写映射）

`aw9523_apply_output` 把缓存打到 `DIM0` 起连续 16 字节，对应关系是：

| DIM 寄存器 | 引脚 |
|------------|------|
| DIM0~3 `0x20~0x23` | P1_0 ~ P1_3 |
| DIM4~11 `0x24~0x2B` | P0_0 ~ P0_7 |
| DIM12~15 `0x2C~0x2F` | P1_4 ~ P1_7 |

业务只调 `io_virtual_led_set` → `aw9523_set_pin_ledval`。
